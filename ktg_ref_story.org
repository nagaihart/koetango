  + ストーリー
    + 昭和12年(1937)兄４人姉１人弟１人の６人兄弟の女の末っ子として生まれる。

    + 小学校高学年で不登校になり中学校はまともに行かない。
    + 昭和30年18歳の時,姉を頼って鹿児島県相良郡より福岡県宗像郡へ就職する。
      + 朝、日豊本線加治木より乗車、西鹿児島に到着
      + 鹿児島本線の西鹿児島駅より蒸気機関車にて東郷駅に６時間かけて到着する。
      + 夕刻東郷駅から路線バス神湊行きで桝丸バス停に到着する。
    + 農家(坂屋敷)のおなごしとして働く。
      + 煤のついた顔を姉に拭いてもらいお苑の隅で姉と簡素な食事をとる。
      + 姉と同じ布団で就寝する。
      + 姉とおなご衆として仕事をする。
    + 農家(力丸家)のおなごしとして働く。
      + 力丸家の主人と奥さんに可愛がられ福岡の父母とよぶ。
      + 永井家(向かえの長男：利雄)と見合い
      + 鹿児島帰省の度主人にかならず帰ってこいといわれる。
      + 主人が鹿児島にきて結婚の申込をする。
      + 結婚し一男二女を設ける。
