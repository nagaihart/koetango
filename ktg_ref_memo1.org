 + 博多駅
   しょうこが到着した博多駅は第２代目である。ルネサンス様式として1909(明治42年)年建築され、
   現在の地下鉄祇園付近の大博通りを縦断して中央に駅舎を構えていた。
   1963年(昭和38)に壊されて現在の博多シティーの位置に移転するまで
   九州第一の都市の玄関として人々の暮らしを支えていた。
   くらしというより時代を支えていた、遠賀川流域の赤線地帯から送られる日本人たち彼女らは女は戦地には送ることが
   できたいので物資として博多港から送られてきた。彼女らは日本人の従軍慰安婦だった。
   おおくの復員兵は博多港に到着した後この博多駅から全国の我が家に帰って行った。
   駅舎の特徴は中央にドーム型の窓が３つ並び中央の窓の上方に三角の屋根
   少し小さい屋根を左右の端に乗せて柱もアーチ構造をいくつも取り入れていた。
   時代を半世紀も支えてきたルネサンス建築は"きっぷうりば"や日本食堂を
   立てましされて高度成長時代の要求を少しずつ変化に表していた。
   駅舎内には鉄道弘済会売店も有していたがKIOSK=キヨスクと名前は変えるまであと15年(1973)も
   有することになる。
   第２代博多駅は３面のホームと５線を有した九州最古の駅のひとつであった。
   駅舎の中央の改札口を出ると第1プラットホームが東西に伸びてその両端に
   第2・第3プラットホームへの連絡橋が備わっている。
   各ホームにはスレートの屋根を連絡橋の階段まで覆っている。
   乗り入れは門司港-鹿児島間の鹿児島本線のみである。
   篠栗線はまだ乗り入れていない。
   博多口にあたる駅前は西鉄の路面電車やバス、人や貨物のための車両で賑わっていた。

* <2021-04-18 Sun> 硬貨歴史
 + 1953年（昭和30年）貨幣単位「銭」が廃止され、単位が「円」のみとなる。
 + 1955年（昭和30年）6月1日：現行1円硬貨流通開始。素材はアルミニウム。
 + 1955年（昭和30年）9月1日：50円硬貨流通開始。素材はニッケル。図柄は菊の花一輪。
 + 1957年（昭和32年）12月11日：100円硬貨流通開始。素材は銀。図柄は鳳凰。
 + 1959年（昭和34年）2月16日：現行10円硬貨流通開始（側面の溝の無い新しいデザインに変更）。
 + 1959年（昭和34年）2月16日：100円硬貨の図柄が鳳凰から稲穂へと変更される。
 + 1959年（昭和34年）2月16日：50円硬貨のデザインを穴の空いた形状へ変更する。
 + 1959年（昭和34年）9月1日：現行5円硬貨流通開始（字体を旧字体から新字体、楷書体からゴシック体へ変更）。
 + 1967年（昭和42年）2月1日：現行100円硬貨流通開始（素材が銀→白銅へ、図柄も桜の花三輪へと変更）。
 + 1967年（昭和42年）2月1日：現行50円硬貨流通開始（素材がニッケル→白銅へ変更、デザイン変更、直径縮小）。
 + 1982年（昭和57年）4月1日：500円硬貨流通開始。素材は白銅。
 + 2000年（平成12年）8月1日：現行500円硬貨流通開始（偽造防止を図るため、素材をニッケル黄銅とし、デザインを変更し、潜像を施した）。
 + 2021年度（令和3年度）下半期以降予定：偽造防止を図るため、500円硬貨の素材およびデザインを変更し、3層構造のバイカラー・クラッド硬貨となる予定。
